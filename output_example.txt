[size=18][b]Description:[/b][/size]
Welcome to The Anarchy Solo Challenge. Every month, we'll play a randomly generated setup with fully scripted rounds of attack cards and a domain deck.
The deck of 24 domain cards are shuffled, drawn until completed, per the rule book and shuffled again 4 times to be able to make the full list of 102 cards (calculated maximum number of domain cards per play).

Let's see who can get the highest score!

The source code for the challenge is located at [url=https://github.com/nikkon226/anarchy-solo-challenge]https://github.com/nikkon226/anarchy-solo-challenge[/url]. If there are any issues or errors, please let me know!

[size=18][b]Rules:[/b][/size]
- All regular solo rules apply
- Use the Domain Cards in order so everyone has the same randomized set per challenge. It might help to track what card is next or how many you have used so you can select the next one in the series
- Some of the card names, descriptions, types, etc. have ending periods ("."). This is done so that the spoiler tags are all the same length and can't be inferred, whether intentional or not.
- Only your [b]first blind play[/b] will count, but play as many times as you wish!
- All are welcome to join
